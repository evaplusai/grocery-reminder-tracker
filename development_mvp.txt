# Grocery Reminder Tracker - MVP Specifications

## MVP Architecture: Full-Stack Vercel Deployment

### Technical Stack
- **Frontend**: NextJS 14 + TypeScript + Tailwind CSS
- **Backend**: Vercel Serverless Functions (API Routes)
- **Database**: Vercel Postgres (or Neon/Supabase)
- **AI**: OpenAI API integration
- **Deployment**: Single Vercel deployment for both frontend and backend
- **Scaling**: Serverless auto-scaling included

## Core MVP Features (4-Week Sprint)

### 1. Voice-Powered Item Addition ⭐
**Description**: Primary feature - voice input for adding grocery items
- Large voice button as main interface
- Web Speech API for voice-to-text conversion
- OpenAI API to parse: "Add [item] to [store]" or "I need [item]"
- Show transcript for user confirmation
- Manual text input as fallback
- Basic error handling for voice failures

### 2. AI Store Assignment ⭐
**Description**: Intelligent store assignment using OpenAI
- Parse voice commands to extract item and store
- When store not specified, AI suggests best store based on item type
- Store suggestions based on item characteristics:
  - Costco: bulk items, household goods
  - ShopRite: general groceries, fresh produce  
  - CVS: pharmacy, convenience items, health products
  - Stop and Shop: full grocery, deli items
- User can override AI suggestions
- Learn from user corrections (simple feedback)

### 3. Multi-Store Lists
**Description**: Separate lists for each store
- 4 fixed stores: ShopRite, Costco, Stop and Shop, CVS
- Store tabs for easy navigation
- Each store has independent shopping list
- Show item count per store
- Store-specific icons/colors for visual distinction

### 4. Basic List Management
**Description**: Essential CRUD operations
- Add items (voice or manual)
- Edit item names and quantities
- Delete individual items
- Mark items as completed/purchased
- Bulk clear completed items
- Simple search within store lists

### 5. Shopping Mode
**Description**: Optimized interface for in-store shopping
- Toggle to shopping mode with larger UI elements
- Large checkboxes for easy tapping while shopping
- Clear visual distinction between completed/pending items
- Progress indicator showing completion percentage
- Simple undo for accidental completions

### 6. Responsive Mobile-First Design
**Description**: Clean, simple interface focused on mobile
- Mobile-first responsive design
- Large touch targets (minimum 44px)
- Simple navigation between stores
- Fast loading and smooth interactions
- Basic light/dark theme support

## Simplified Technical Requirements

### Frontend (NextJS on Vercel)
```typescript
// Core pages structure
pages/
  api/          // Vercel serverless functions
  _app.tsx     // App configuration
  index.tsx    // Main dashboard with store tabs
  [store].tsx  // Store-specific list view

components/
  VoiceButton.tsx        // Main voice input component
  StoreList.tsx         // Store-specific shopping list
  ItemCard.tsx          // Individual grocery item
  ShoppingMode.tsx      // Toggle for shopping interface
```

### Backend (Vercel API Routes)
```typescript
// API endpoints structure
api/
  auth/
    login.ts           // User authentication
    register.ts        // User registration
  
  stores/
    index.ts           // Get all user stores
    [store]/
      items.ts         // CRUD operations for store items
  
  ai/
    parse-voice.ts     // OpenAI voice command parsing
    suggest-store.ts   // AI store assignment
```

### Database Schema (Simplified)
```sql
-- Core tables only
users (id, email, created_at)
stores (id, name, icon, characteristics)  
items (id, user_id, store_id, name, quantity, completed, created_at)
voice_commands (id, user_id, transcript, parsed_result, success)
```

### OpenAI Integration (Single Purpose)
```typescript
// Simplified AI prompts
const VOICE_PARSING_PROMPT = `
Parse grocery voice command and return JSON:
{
  "action": "add",
  "items": ["item name"],
  "store": "ShopRite|Costco|Stop and Shop|CVS|null",
  "confidence": 0.0-1.0
}

If no store specified, suggest best store for the items.

User said: "{transcript}"
`;
```

## Scaling Strategy on Vercel

### Why Vercel for Full-Stack:
- **Serverless Auto-scaling**: Backend scales automatically with usage
- **Edge Distribution**: Global CDN for fast frontend delivery
- **Integrated Database**: Vercel Postgres scales with application
- **Zero DevOps**: No server management or infrastructure complexity
- **Cost Efficiency**: Pay only for actual usage
- **Easy Deployment**: Single git push deploys full-stack

### Vercel Scaling Benefits:
- Functions scale to zero when not used
- Database connection pooling handled automatically  
- Edge caching for static assets and API responses
- Built-in monitoring and analytics
- Easy environment variable management for OpenAI keys

This MVP approach focuses on the core value proposition - voice-powered grocery lists with intelligent store assignment - while keeping technical complexity minimal and leveraging Vercel's full-stack serverless platform for effortless scaling.
